#Half wave rectifier 
##Description
This project demonstrates the operation of a half-wave rectifier using Pspice.

A diode is used to convert the AC input signal into a pulsating Dc output.

##components used
1.ac voltage souce (vsin)
2.Diode (d1n4002)
3.resistor(1khz)
4.ground (0 source)

##Simulation
the circuit was designed and simulated using pspice.

##Result

The input Ac wavefom and the half wave rectified waveform are shown in screenshot,
Here the diode is inverted so the output is negative half-wave pulsating DC waveform
